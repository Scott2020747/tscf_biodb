Project Overview

The TSCF Vision Partners Application is a full-stack web application designed to manage membership applications for the Tertiary Students Christian Fellowship. The system allows prospective members to submit their bio-data, select membership types, make financial contributions, and enables administrators to manage and track applications efficiently.

Key features: Member registration, donation pledges, graduate programs selection, admin dashboard with status approval/rejection, real-time form validation, and responsive UI built with Tailwind CSS.

Installation Guide

Prerequisites: Node.js v18+, npm v9+, PostgreSQL v14+
# 1. Clone repo
git clone https://github.com/your-username/tscf-vision-partners.git
cd tscf-vision-partners

# 2. Setup PostgreSQL database
psql -U postgres -f database.sql

# 3. Backend setup
cd backend
npm install
cp .env.example .env   # then edit DB_PASSWORD
npm run dev            # runs on http://localhost:5000

# 4. Frontend setup (new terminal)
cd frontend
npm install
npm start              # runs on http://localhost:3000

Ensure your .env inside backend contains: DB_USER, DB_PASSWORD, DB_HOST, DB_PORT, DB_DATABASE, PORT=5000. The frontend proxy points to backend at port 5000 automatically.

API Documentation

Base URL: http://localhost:5000/api

GET /members – Retrieve all applications
GET /members/:id – Get single member
POST /members – Create new application (JSON body with all fields)
PUT /members/:id/status – Update status (pending/approved/rejected)
DELETE /members/:id – Delete application

Example POST request body:

{
  "surname": "Doe", "given_name": "John", "email": "john@tscf.org",
  "membership_type": "Student Member", "mobile": "73277901"
}

Development Workflow

  • Use feature branches: git checkout -b feature/your-feature
  • Commit convention: feat:, fix:, docs:, style:, refactor:, test:, chore:
  • Run backend in dev mode: npm run dev (nodemon hot reload)
  • Run frontend: npm start with proxy to backend
  • Build frontend: npm run build → static files in build/

Deployment Guide

Troubleshooting

❌ Database connection error: Verify PostgreSQL is running and .env credentials correct.
❌ Port 5000 already in use: lsof -i :5000 then kill process or change PORT in .env.
❌ CORS / frontend can't reach API: Ensure backend proxy is configured in frontend package.json ("proxy": "http://localhost:5000") or use environment variable.
❌ Module not found: Delete node_modules and run npm install again in both folders.
